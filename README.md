# intercity-demand
Intercity Demand Radar:
A demand aggregation platform for shared intercity taxis (Delhi → Uttarakhand MVP).

Problem:
Intercity shared taxi drivers currently rely on phone calls and WhatsApp groups to check seat availability. This creates inefficiency and uncertainty in departure planning.

Solution:
A real-time demand visibility platform where:
Passengers register travel intent.
Drivers can see total seat demand on a route.
Departure is confirmed once minimum seats are filled.

Features:
Live passenger demand counter
Boarding point aggregation
Seat fill probability
Minimum seat departure trigger
Role-based login (Driver / Passenger)

Tech Stack:
Backend: FastAPI
Database: PostgreSQL
Frontend: React
Deployment: Render / Railway

Future Scope:
Route optimization
Predictive demand analytics

Driver subscription model

Taxi union integration
